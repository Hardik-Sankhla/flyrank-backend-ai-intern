# Assignment Validation Skill

## Objective
Ensure that internship assignments meet their stated criteria without confusing them with production code.

## Instructions
1. **Isolate Scope**: Treat each assignment (e.g., `assignments/FL-01-workflow-audit`) as an isolated entity. Do not intermingle logic between disparate assignments.
2. **Verify Requirements**: Read the assignment's `README.md` or prompt documents to understand the goals.
3. **Avoid Over-Engineering**: Do not apply production-level architecture (e.g., microservices, complex databases) to simple assignments unless requested.
