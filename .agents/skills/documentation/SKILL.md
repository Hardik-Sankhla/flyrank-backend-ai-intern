# Documentation Skill

## Objective
Maintain accurate and synchronized documentation.

## Instructions
1. **Synchronize**: When updating code, always update the relevant documentation (e.g., `README.md`, `docs/`).
2. **Accuracy**: Never invent or document features, APIs, or architectural components that do not currently exist in the codebase.
3. **Differentiate**: Clearly distinguish between verified facts, inferred information, and planned/future architecture.
