# Repository Navigation Skill

## Objective
Enable the agent to effectively navigate the `flyrank-backend-ai-intern` repository.

## Instructions
1. **Start with the Map**: Before attempting to modify or search for a feature, read `docs/REPOSITORY_MAP.md`.
2. **Identify the Type of Code**: Distinguish between internship assignments (e.g., `assignments/`) and project code (`projects/` or `scripts/`).
3. **Authoritative Files**: 
   - `pyproject.toml` and `uv.lock` dictate the environment and dependencies.
   - `AGENTS.md` provides global agent instructions.
4. **Tool Preference**: Use `grep_search` and `list_dir` to explore the codebase before using broader terminal commands.
